# Creator 21.0 Editorial Policy

Creator 21.0 is an evidence-based editorial layer. It is not a publisher and does not bypass existing gates.

## Primary objective
Increase content quality and reader value by selecting strong, specific, evidence-supported angles instead of maximizing raw posting frequency.

## Required behavior
- Generate multiple candidate hooks before selecting an angle.
- Prefer a clear thesis, implication, question, disagreement, or data story when supported by evidence.
- Reject generic price recaps unless there is a material contextual reason to publish.
- Use visuals to explain a claim, not merely decorate the post.
- Learn from observed outcomes only; minimum three samples are required before treating a pattern as meaningful.
- Treat views, likes, replies, quotes and shares as engagement evidence, never as revenue.
- Never infer earnings from views or engagement.
- Never fabricate engagement, sources, facts, or certainty.
- Never guarantee investment returns.
- If evidence is weak, return RESEARCH_AND_WAIT rather than filler.

## Success measurement
The system should optimize sequentially for reach, engagement quality, follower growth, verified conversion and explicitly verified revenue. Revenue remains zero/unknown unless the data source explicitly verifies it.
